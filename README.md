## 先想清楚：你到底要用这台 VPS 干什么

低价 VPS 的使用场景差别很大，配置和线路选择也完全不同。常见的几类需求：

- **学习 Linux / 折腾环境**：1 核 512MB 内存的小机器就够，对线路要求低，便宜的常规机房 VPS 即可。
- **个人博客或小型建站**：需要稳定性和一定带宽，1GB 内存起步更稳妥，机房最好离访客近。
- **科学上网 / 代理转发**：对线路质量敏感，国内回程走 CN2 GIA 或 CMIN2 的机房体验明显更好，价格也更高。
- **跑轻量服务（监控、Bot、定时任务）**：看重稳定运行时间，对带宽和延迟要求不高。
- **外贸 / 面向中国访客的业务**：需要中国方向优质线路，通常选 CN2 GIA-E 或香港 / 日本机房，价格跨度大。

如果你只是想花最少的钱练手，年付 $49.99 的入门款就够用。如果你要跑代理或对国内访问速度有要求，便宜的标准 VPS 大概率会让你失望——这时候"便宜"的定义要往 CN2 GIA 系列靠。

## 便宜 VPS 的几个关键判断指标

价格只是表象，真正决定体验的是下面这些参数。买之前对着清单核对一遍，比看商家宣传靠谱。

**CPU 与内存**：1 核 1GB 是入门门槛，跑个 SSH、小型 Web 服务够用。2 核 2GB 起步才能比较从容地跑带数据库的站点。超售严重的商家，CPU 实际可用性能会大打折扣，这点只能靠口碑和实测判断。

**存储类型**：RAID-10 SSD 或 NVMe SSD 是当前主流，HDD 方案已经不推荐。存储大小要根据你跑的服务估算，20GB 起步对小站点足够。

**月流量（Transfer）**：注意是流量不是带宽。1TB/月对个人使用绰绰有余；跑代理或大文件下载要算清楚。超出后通常是限速或停机，不是免费。

**带宽（Link Speed）**：1Gbps、2.5Gbps、10Gbps 的差别在峰值时段才明显。低价套餐通常 1Gbps，CN2 GIA-E 套餐普遍 2.5Gbps 起步。

**机房与线路**：这是国内用户最该关注的维度。同一个商家，普通机房和 CN2 GIA 机房的国内访问体验可能差一个数量级。后面会具体讲搬瓦工的线路分级。

**计费周期**：年付通常比月付便宜，但要注意是否有循环折扣、续费价格是否上涨。年付 $49.99 摊到每月约 $4.17，但要一次性掏出来，且商家跑路风险自担。

**退款政策**：30 天退款是行业常见标准，低于这个的要谨慎。
